# GBA Ticket Tool

Mobile-first ticket & project tracker for a 5-person team on the Bengaluru 100-Day Program (Greater Bengaluru Authority).

**Stack:** Next.js (PWA) + Supabase (Postgres / Auth / Realtime), deployed on DigitalOcean.
